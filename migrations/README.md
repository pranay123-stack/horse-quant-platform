# Migrations

Alembic migrations for the Horse Quant Platform.

```bash
# create a new revision from the ORM models
alembic revision --autogenerate -m "add races table"

# apply everything
alembic upgrade head

# roll back one revision
alembic downgrade -1

# preview the SQL without touching the database
alembic upgrade head --sql
```

Rules:

1. **Always review autogenerated migrations.** Alembic does not detect column
   renames, server-default changes on existing rows, or data migrations.
2. **Every migration must have a working `downgrade()`.** The constraint naming
   convention in `backend/database/base.py` exists so this is possible.
3. **Import every new model in `backend/models/__init__.py`** or autogenerate
   will silently omit its table.
